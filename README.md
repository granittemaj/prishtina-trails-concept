# Prishtina Trails: website concept

A design concept for the Prishtina Trails 2027 website. **Not the official site**; the official site is [prishtinatrails.com](https://prishtinatrails.com/).

Pages:

- `index.html`, the main site
- `register/`, a registration concept: race picker with places left, runner details (with a guardian flow for the kids' races), a donation of any amount, review, and a bib that fills in as you type. It stops before any payment.

On the main page:

- Course explorer with the real 10K, 23K and 50K routes, drawn from the race's published GPX files, on Leaflet with Map / Satellite / Terrain basemaps
- Elevation profile linked to the map, "Run the course" playback, and a pace-to-finish-time calculator checked against each cut-off
- Light and dark themes, responsive down to phone width, reduced-motion support

Photos, logos and race information belong to Prishtina Trails / X Trailers running club. Map data © OpenStreetMap contributors; tiles © Esri and OpenTopoMap.
